# 📌 MVP - [Simga2.0] (Sprint 2)

## 🎯 Objetivo do MVP
> O objetivo da segunda srpint é expandir as funcionalidade do dashboard, adicionando recursos e mais interações entre as informações da base de dados de exportação queu foram coletadas
- Nessa sprint o time deve:
- Usar todas as ferramentas adequadamente
- Registrar todos os passos
- Adicionar as novas funcionalidades como:
- Mapa mundial onde mostras de forma gráfica onde estão os maiores importadores no globo
- Adicionar ao dashboard quais estados mais exportam
- Adicionar ao dashboard quais os principais centros de escoamentos para essa carga
- Com os papeis e prazos bem definidos os membros devem entregar sem atraso as melhorias

---

## 📝 Descrição da Solução
> Funcionalidades principais incluídas:  
- Mapa mundi com todas as informações integradas
- dashboard com quais estados mais exportam
- dashboard quais os principais centros de escoamentos para essa carga
- Limitações conhecidas:
- Design do layout ainda bem simples apenas para validar a ideia
- Escopo reduzido (somente o essencial para validar a ideia)
  
---

| US4 | Como aluno de gestão, eu quero visualizar quais estados brasileiros mais exportam, para identificar as principais origens nacionais da carga.         | Média      | 3 pontos   |

| US6 | Como aluno de gestão, eu quero interagir entre os gráficos e filtros, para cruzar informações de países importadores, estados exportadores e centros de escoamento.        | Alta       | 5 pontos   |
